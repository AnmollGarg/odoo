Free Shipping Product Fix for Loyalty

Keep your Odoo product catalog clean and prevent duplicate Free Shipping products.

The Problem

By default, when you create a Loyalty Reward for "Free Shipping" in Odoo, the system automatically generates a brand new service product every single time. If you have multiple free shipping programs or promotions, you end up with multiple identical "Free Shipping" products cluttering your catalog.

The Solution

This module elegantly overrides this behavior. It intercepts the creation of these rewards and reuses an existing "Free Shipping" product. It automatically searches for a matching service product based on the reward description, keeping your catalog perfectly clean and preventing any unwanted duplicates.

Features

  • Zero Configuration Required
  • Works for all Loyalty Rewards
  • Preserves Standard Odoo Workflows
